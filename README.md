# TJ Terraplanagem

Site institucional em Next.js e Tailwind CSS.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Vídeo do hero

O site está pronto para vídeo. Coloque o arquivo de vídeo em `public/hero.mp4` para ativá-lo automaticamente. Sem vídeo, o hero usa a foto da escavadeira como fallback.
